# Estação Interativa dos Objetos

Experiência interativa para instalação permanente na Casa de Metal Centro Cultural: telas touchscreen em modo quiosque onde visitantes investigam objetos cotidianos e descobrem os metais e minerais que os compõem.

> ***Status:** em desenvolvimento - Etapa 01 de 25.

## Escopo

A experiência investiga exclusivamente metais, ligas, minerais, minérios, cerâmicas e refratários.

## Stack prevista

- React + TypeScript + Vite
- Zustand (estado) + GSAP (motion) + Zod (validação de dados)
- Electron (aplicação desktop em modo quiosque, Windows 11)
