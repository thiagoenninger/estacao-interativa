# 0001 - Registrar decisões de arquitetura

- **Status** aceita
- **Data** 28-09-2026

## Contexto

O projeto será mantido por anos e receberá novas versões de conteúdo. As decisões técnicas tomadas agora precisam continuar compreensíveis no futuro.

## Decisão

Toda decisão arquitetural importante é registrada em `docs/decisoes/` como um ADR numerado e curto. Mudanças de rumo geram novo ADR que substitui o anterior.

## Consequências

- O histórico de "por que" fica junto do código, versionado pelo Git.
- Cada decisão exige alguns minutos de escrita.
