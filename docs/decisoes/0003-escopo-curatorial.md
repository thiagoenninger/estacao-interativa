# 0003 — Escopo curatorial
 
- **Status:** aceita
- **Data:** 28-09-2026
 
## Contexto
 
Os objetos contêm muitos materiais, mas a experiência investiga a cadeia dos
recursos minerais.
 
## Decisão
 
Aparecem na órbita apenas metais, ligas relevantes, minerais, minérios,
cerâmicas, refratários e matérias-primas minerais. Borracha, polímeros,
plásticos, vidro, silício, couro, tecidos, madeira, espumas, entre outros
não são opções de investigação. As partes do desenho feitas desses
materiais continuam no SVG como estrutura e recuam quando outro material é
destacado.
 
## Consequências
 
- A lista final só terá objetos com 3 a 8 materiais dentro do escopo.
- O validador de dados (Etapa 04) recusa materiais fora do escopo na órbita.
